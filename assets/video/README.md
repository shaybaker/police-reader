# תדריכי וידאו

בגרסה הזו התדריך של מנהל התחנה הוא אנימציה מקומית שנבנית בתוך המשחק, כדי שהמשחק יעבוד גם ללא אינטרנט וללא שימוש בתוכן מוגן.

אפשר להוסיף בעתיד קטעי וידאו חינמיים או קטעים שהוקלטו במיוחד לתיקייה הזו. אין להוסיף חומר מהרשת בלי לבדוק רישיון שימוש. אם מוסיפים קובץ `mission-complete.mp4`, ניתן לחבר אותו למסך התדריך במקום האנימציה.
