# קובצי שמע בעברית

המשחק כולל קובצי WAV מקומיים שנוצרו בקול העברי Carmit של macOS, עם טקסט עברי מנוקד כדי לשפר את ההגייה. הוראות היסוד והמילים המרכזיות נשמעות גם ללא אינטרנט:

- `instruction-read.wav` — הוראת הקריאה
- `instruction-write.wav` — הוראת הכתיבה
- `instruction-sounds.wav` — הוראת מעבדת הצלילים
- `mishtara.wav`, `nayadet.wav`, `shoter.wav`, `mapa.wav`, `mafteach.wav`, `tik.wav` — מילים לתרגול

הקבצים הם TTS איכותי, לא הקלטה של אדם אמיתי. כדי לקבל קול אנושי ממש, אפשר להחליף אותם בהקלטות של מורה או בן משפחה, או בקול ממחולל TTS/AI שיש לכם עבורו הרשאת שימוש. טקסטים דינמיים מקבלים ניקוד הגייה ומושמעים בקול העברי המותקן במחשב כגיבוי. אין להכניס הקלטות של ילד ללא אישור הורה/אפוטרופוס.
