# הקלטות קול אנושי

המשחק תומך בהקלטות קול אנושי מקומיות. כדי להחליף את הקראת המערכת בקול של מורה או בן משפחה, הוסיפו לכאן את הקבצים הבאים:

- `mishtara.mp3` — “משטרה”
- `nayadet.mp3` — “ניידת”
- `shoter.mp3` — “שוטר”

הקבצים אינם נשלחים לשירות חיצוני ונשארים בתוך המשחק. אם קובץ חסר או לא ניתן לנגן אותו, המשחק משתמש בקול העברי המותקן במחשב כגיבוי.
