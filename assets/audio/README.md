# הקלטות קול אנושי

המשחק תומך בהקלטות קול אנושי מקומיות. כדי להחליף את הקראת המערכת בקול של מורה או בן משפחה, הוסיפו לכאן את הקבצים הבאים:

- `mishtara.mp3` — “משטרה”
- `nayadet.mp3` — “ניידת”
- `shoter.mp3` — “שוטר”

אפשר ליצור את הקבצים בקול אנושי או במחולל TTS/AI שיש לכם עבורו הרשאת שימוש. הקבצים אינם נשלחים לשירות חיצוני ונשארים בתוך המשחק. אם קובץ חסר או לא ניתן לנגן אותו, המשחק משתמש בקול העברי המותקן במחשב כגיבוי. אין להכניס הקלטות של ילד ללא אישור הורה/אפוטרופוס.
