# קובצי שמע בעברית

המשחק כולל קובצי WAV מקומיים שנוצרו בקול העברי Carmit של macOS, ולכן הוראות היסוד והמילים המרכזיות נשמעות גם ללא אינטרנט או ללא התקנת קול עברי ב־Windows:

- `instruction-read.wav` — הוראת הקריאה
- `instruction-write.wav` — הוראת הכתיבה
- `instruction-sounds.wav` — הוראת מעבדת הצלילים
- `mishtara.wav`, `nayadet.wav`, `shoter.wav`, `mapa.wav`, `mafteach.wav`, `tik.wav` — מילים לתרגול

אפשר להחליף את הקבצים בהקלטות של מורה או בן משפחה, או בקול ממחולל TTS/AI שיש לכם עבורו הרשאת שימוש. הקבצים נשארים בתוך המשחק. טקסטים דינמיים, כמו משוב אישי של מנהל התחנה, משתמשים בקול העברי המותקן במחשב כגיבוי. אין להכניס הקלטות של ילד ללא אישור הורה/אפוטרופוס.
